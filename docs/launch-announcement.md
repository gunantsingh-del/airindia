# Air India Virtual — now boarding.

Fourteen pilots. One closed roster. A crew portal that doesn't apologise for being aviation software.

The wait is over. AIVA goes live today at **airindiavirtual.online**, and on your desktop as a native Windows app at **airindiavirtual.online/install**.

This isn't another fan-site flight tracker. It's the operations terminal for our cohort — built from the ground up around how Air India and Air India Express actually fly.

---

## What's inside

**Network and schedule**
- 1,100+ hand-curated sectors across the full AIC and AXB fleet
- Real published schedules for trunk routes; airline-correct synthetic timing for every other flight
- 100+ destinations from Delhi to San Francisco, Melbourne, Newark and back
- Live network globe with great-circle arcs, flown-pair tracking, per-airport flight finder

**Roster tools**
- Three booking modes — Search and Book, auto-generated rotations, full Monthly Bid with off-day grid
- Type-rating filters that respect real airline substitution: A320 family unified, 737 family unified, widebodies kept strict
- FDTL guard so impossible duty days never reach your calendar
- Calendar view with multi-sector days, one-tap clear, full month overview

**OFP and dispatch**
- Full SimBrief Dispatch integration — generate, fetch, file
- File flight plans directly from the portal or EFB; callsign discipline enforced (AIC or AXB only, no fictional numbers)
- All filed plans land in the Chief Pilot's review queue
- Pull the latest OFP back into AIVA with TOW, fuel, alternate, route, AIRAC, PDF link

**Electronic Flight Bag**
- Cockpit-style iPad layout
- Briefing pack, NOTAM, METAR, TAF, D-ATIS, VATSIM ATIS, charts, embedded Windy
- Live FSUIPC telemetry tile with auto-detect
- Weight and Balance for the full fleet
- Performance reference card
- MEL quick-lookup table

**Live tracking**
- FSUIPC7 WebSocket bridge with background auto-detect — turn on the sim, AIVA's topbar chip flips green within five seconds, Start Flight unlocks
- Real-time position, altitude, IAS, ground speed, vertical speed, heading, fuel
- Auto-detection of descent through 10,000 ft, landing, sim crashes
- Auto-logged sectors with block time and distance on flight end

**Crew comms**
- Real-time group chat that syncs across devices, not just same-browser localStorage
- Auto-generated ops events: sign-on, departure, passing 10k, landing
- Hoppie ACARS with auto-dispatch on threshold crossings
- Presence indicator, online roster, message history

**Admin and discipline**
- Review queue for manual flight claims, crash reports, filed flight plans, and crew inquiries
- Per-pilot data isolation — two pilots on the same browser keep separate state
- Rank progression: Cadet → First Officer → Senior First Officer → Captain → Senior Captain
- Maharaja Club for the founding cohort

**Welfare and identity**
- Profile picture, type ratings, SimBrief username, Hoppie logon, callsign — all per-pilot
- Hire date, medical class, base, fleet authorisations on the crew roster
- Newsroom feed, in-app announcements with FSUIPC playback hooks, layover and hotel directory

**Distribution**
- Browser portal at airindiavirtual.online
- Installable PWA — desktop-style, no install dialog
- Native Windows desktop app — branded with the AIVA chakra, NSIS installer, Start Menu shortcut, opens chromeless, bypasses HTTPS Mixed-Content blocking so the FSUIPC bridge connects directly
