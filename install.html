Installation — under 60 seconds

01 Download

Click the red button above. AIVA-Setup.exe starts downloading from our release CDN (~90 MB). Save it to your Downloads folder.

02 Run the installer

Double-click AIVA-Setup.exe. Windows SmartScreen may ask if you want to run an unsigned app — click More info → Run anyway. Pick an install location or accept the default.

03 Launch from Start Menu

An AIVA shortcut lands on your Desktop and in the Start Menu, both branded with the chakra. Click it to open the portal in its own window.

04 Start FSUIPC and fly

Open MSFS and FSUIPC WebSockets Server (with SSL off — the .exe handles plain ws:// fine). AIVA's topbar chip flips to FSUIPC ● within 5 seconds. Start Flight unlocks. Track your sectors.

Why a desktop app?

Modern browsers block plain ws:// connections from HTTPS pages — even to localhost. That's why pilots running the AIVA website in Chrome see "Cannot reach FSUIPC" even with the WebSockets Server clearly Running.

The desktop wrapper loads the same portal but bypasses the Mixed-Content rule, so FSUIPC connects directly with no certificate setup. Everything else — your roster, briefing, ACARS, crew chat — works identically.

If you'd rather stay in the browser, the SSL workaround in Profile → FSUIPC setup works too — tick "Use SSL" in the FSUIPC WebSockets Server and accept the self-signed cert once.
